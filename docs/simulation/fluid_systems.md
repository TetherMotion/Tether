# Fluid Systems

This module contains various simulation models for fluid systems.

## Advantages and Disadvantages
* **Advantages**: Highly accurate parameterization for well-known fluid phenomena.
* **Disadvantages**: Can be computationally expensive depending on solver stiffness.

## Mathematical Details
The system dynamics are generally formed as state-space equations: $\dot{x} = f(x, u, t)$, where $x$ is the state vector and $u$ is the input vector.
